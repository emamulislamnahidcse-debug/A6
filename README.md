# 🏋️‍♂️ FitLog — Dark-Themed Workout Companion

**FitLog** is a responsive, dark-themed gym tracking and workout library web application built with **Next.js (App Router)** and **Tailwind CSS**. Designed for gym enthusiasts, it allows users to explore various exercises, view detailed muscle group breakdowns and instructions, and organize their workouts into a daily plan.

## ✨ Key Features

- **🏋️ Workout Library:** Displays detailed exercise cards with muscle group badges, estimated duration, burned calories, and ratings.
- **🔍 Search & Dynamic Filtering:** Filter exercises instantly by title, muscle category, or equipment.
- **📊 Interactive Sorting:** Sort workouts dynamically by duration, calories burned, or rating.
- **📖 Comprehensive Workout Details Page:** Includes structured equipment data, difficulty levels, target muscle badges, and step-by-step exercise instructions.
- **📋 Plan & Save Management:** Add exercises directly to your daily training schedule or save them for later access.
- **🎨 Dark Mode Aesthetic:** Designed with a sleek, high-contrast dark theme and vibrant neon accent colors for modern gym vibes.
- **📱 Fully Responsive:** Perfectly optimized across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Client Components)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & Assets:** Custom SVG icons & optimized Next.js Image components
- **Language:** TypeScript
- **Deployment:** [Vercel](https://vercel.com/)
